# 선장의 아쿠아리움

바다를 사랑하는 선장이 보물을 팔아 수족관을 짓고, 선원들과 바다의 소중함을 알리는 스마트폰 게임 시제품입니다. 제주는 첫 배경이며 다른 지역은 구현 전입니다.

[게임 열기](https://wishjosh.github.io/captains-aquarium/?v=2026-10-18-underwater-four-fish-1)

현재 검토 버전은 `2026-10-18-underwater-four-fish-1`입니다. 제주풍의 짙은 암반·모래 공터·일반 해조류 배경과 물의 흐름에 따른 느린 흔들림을 적용했습니다. 감태·모자반의 정확한 모델과 특정 해역의 복원은 후속 검토입니다. 움직임 줄이기 설정에서는 해조류가 현재 자세에 멈춥니다.

Quaternius 무료 원본을 바탕으로 흰동가리·가시복·깃대돔·뿔복 네 생물을 수집합니다. 원본 형태·뼈대·수영 동작을 보존하고 승인된 표시용 색·무늬·흰자 눈을 적용합니다. B 조명과 원본 GLB 파일을 유지합니다. 일반 장면의 크기 비율은 8:25:20:30이며 관찰 화면에서는 각 생물을 확대합니다. 이는 검토용 개체 크기이며 종별 평균·최대 크기나 모델의 정확한 종 판정이 아닙니다. 친근해서 먼저 사용한 흰동가리를 제주 야생 생물이라고 설명하지 않습니다. 이전 범돔·자리돔·해파리는 실행에서 제외하되 과거 진행은 보관합니다.

부두 사다리로 내려가기 → 수중 탐색·생물 직접 수집 → 사다리로 귀환 → 조수 운반 → 관리동 입수·상태 확인·먹이 돌봄으로 이어집니다. 한 번에 한 생물을 운반합니다. 관리동 Anne·전시관 Mako가 각각 관리·전시를 맡고 Henry 조수는 선장이 실제로 지나간 길·계단·데크를 따라 생물이 든 수조를 옮깁니다. 전시관 배치·관찰·흰동가리 수조 장식은 별도 흐름입니다. 세 전시 자리에 네 생물을 교체해 놓을 수 있고 교체해도 돌봄·관찰 기록은 남습니다. 관리동의 ‘가까이 보기’에서는 전시 전에도 확대 관찰할 수 있습니다.

스마트폰은 가로로 사용합니다. 왼쪽을 누르고 끌면 수평 이동하며, 수중 오른쪽 세로 조작부로 상승·하강합니다. 두 조작은 함께 사용할 수 있고 손을 떼면 해당 이동이 멈춥니다. 가까운 생물을 직접 눌러 수집하며 먼 대상은 선택·접근 안내만 보여 줍니다. 부두 끝 사다리를 향해 계속 이동하면 내려가고, 수중에서 접근해 상승하면 올라옵니다. 두 손가락이나 휠로 확대·축소하며 시선은 제한된 범위에서 자동 보정합니다. 육지에서는 원래 문을 향해 약 1초 계속 이동하면 출입합니다. 문·사다리에 접근할 때 약 2배 확대했다가 원래 확대 값으로 돌아갑니다. 컴퓨터는 WASD·방향키, Q 상승·E 하강, +/- 확대·축소, 0 확대 초기화를 지원합니다.

진행은 같은 기기·브라우저에 저장되며 기기 간 자동 동기화는 없습니다. 조작 안내의 **저장 기록 옮기기**에서 파일을 내보내고 가져옵니다. 기존 저장 키와 v7 형식을 유지합니다. 이미 진행한 흰동가리 수집·돌봄·관찰·장식은 이어받고 새 세 생물은 미수집 상태로 추가합니다. 첫 확장 저장 전에 기존 저장 문자열을 별도 원본 백업에 남기며 백업이 실패하면 원래 기록을 덮어쓰지 않습니다. 이전 v1~v6 원본과 백업도 보관하고 과거 생물을 새 종으로 이름만 바꾸지 않습니다. 사이트 데이터를 지우면 기록이 사라질 수 있습니다.

분리된 시험 브라우저에서 네 생물 수집·운반·입수·돌봄·확대 관찰·전시 교체·재접속, 이전 저장·장식 보존과 사다리·수심 조작·꾸미기를 검사합니다. 배경의 실제 흔들림·밑동 고정·작은 가로 화면과 기존 생물 연결도 함께 확인합니다. 실제 안드로이드 성능과 사용자의 기기에서 이어받은 기록·조작감은 검토 대기입니다.

## 게시 파일과 실행 방식

`site/`에는 실행에 필요한 명시적 허용 목록의 파일만 둡니다. 개발 비교 화면·시험 코드·개인 저장·원본 Blender 파일은 포함하지 않습니다. 파일 참조에 같은 검토 버전을 붙여 새 화면과 이전 스크립트가 섞이는 것을 줄입니다. GitHub Actions의 **Publish review build**를 `main`에서 수동 실행하면 `site/`를 GitHub Pages에 게시합니다. 검토 버전은 조작 안내와 `site/release.json`에서 확인합니다.
