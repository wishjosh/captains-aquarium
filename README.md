# 선장의 아쿠아리움

바다를 사랑하는 선장이 보물을 팔아 수족관을 짓고, 선원들과 바다의 소중함을 알리는 스마트폰 게임 시제품입니다. 제주는 첫 배경이며 다른 지역은 구현 전입니다.

[게임 열기](https://wishjosh.github.io/captains-aquarium/)

현재 검토 버전은 `2026-10-17-clownfish-lighting-c-1`입니다. Quaternius Cute Fish Pack의 공식 원본 흰동가리 한 종을 사용하며 형태·색·재질·뼈대·수영 동작을 임의로 바꾸지 않습니다. 사용자가 선택한 C 조명으로 실내 반사 환경을 제외하고 주변광을 보완했습니다. 실제 세부 종과 서식 해역은 미정이며 제주 야생 생물이라고 단정하지 않습니다. 이전 범돔·자리돔·해파리와 배경 물고기 무리는 현재 실행에서 제외했습니다.

부두에서 잠수 → 수중 탐색·수집 → 귀환 → 관리동 입수·상태 확인·먹이 돌봄으로 이어집니다. 전시관 배치·관찰·수조 장식은 별도 흐름입니다. 현재 세 수조와 공용 작업 데크·양끝 계단을 유지하며 흰동가리 한 종을 관리합니다.

스마트폰은 가로로 사용합니다. 왼쪽을 누르고 끌면 조이스틱으로 이동하며 손을 떼면 멈춥니다. 물속에서는 오른쪽 화면을 끌어 시선을 바꾸고 바라보는 방향으로 헤엄칩니다. 가까운 생물은 행동 버튼으로 수집하고 입구의 붉은 고리와 줄로 돌아가 귀환합니다. 육지의 원본 건물 문을 향해 약 1초 계속 이동하면 출입합니다. 컴퓨터에서는 WASD·방향키도 사용할 수 있습니다.

진행은 같은 기기·브라우저에 저장되며 기기 간 자동 동기화는 없습니다. 조작 안내의 **저장 기록 옮기기**에서 파일을 내보내고 가져옵니다. 기존 저장 키는 유지하고 형식은 v7입니다. 이전 v1~v6 원본 기록은 `legacyProgress`에 보관하고 첫 저장 전에 별도 원본 백업도 남깁니다. 백업이 실패하면 이전 기록을 덮어쓰지 않습니다. 이전 생물을 흰동가리로 이름만 바꾸지 않으며 흰동가리는 새 수집으로 시작합니다. 원본 기록은 이전 화면에서 별도 내보내기도 가능합니다. 사이트 데이터를 지우면 기록이 사라질 수 있습니다.

원본 형상·재질·동작, 이전 19상태·현재 6단계 저장, 관리동 192경로와 별도 시험 브라우저의 탐사·수집·귀환·돌봄·전시·관찰·꾸미기·재접속을 확인했습니다. 실제 안드로이드 성능과 사용자 기기에서의 외형·기존 기록은 검토 대기입니다.

## 게시 파일과 실행 방식

`site/`에는 실행에 필요한 명시적 허용 목록의 파일만 둡니다. 개발 비교 화면·시험 코드·개인 저장·원본 Blender 파일은 포함하지 않습니다. 파일 참조에 같은 검토 버전을 붙여 새 화면과 이전 스크립트가 섞이는 것을 줄입니다. GitHub Actions의 **Publish review build**를 `main`에서 수동 실행하면 `site/`를 GitHub Pages에 게시합니다. 검토 버전은 조작 안내와 `site/release.json`에서 확인합니다.
