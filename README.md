# 선장의 아쿠아리움

바다를 사랑하는 선장이 보물을 팔아 수족관을 짓고, 선원들과 바다의 소중함을 알리는 스마트폰 게임 시제품입니다. 제주는 첫 탐험 지역이며 다른 지역은 구현 전입니다.

[게임 열기](https://wishjosh.github.io/captains-aquarium/)

부두에서 잠수 → 수중 탐색·수집 → 귀환 → 관리동 입수·첫 돌봄으로 이어집니다. 범돔·자리돔·해파리를 한 마리씩 만나고, 앞선 친구의 돌봄을 마치면 다음 종을 수집할 수 있습니다. 전시·관찰·꾸미기는 원하는 때 별도로 즐깁니다.

휴대폰은 가로 화면으로 사용합니다. 왼쪽을 누르고 끌면 조이스틱으로 이동하며 손을 떼면 멈춥니다. 물속에서는 오른쪽 화면을 끌어 시선을 바꾸고 바라보는 방향으로 헤엄쳐 수심을 바꿉니다. 가까운 생물은 오른쪽 행동 버튼으로 수집하고, 입구의 붉은 고리와 줄로 돌아가면 귀환할 수 있습니다. 빈손 귀환과 이미 만난 생물의 재관찰도 가능합니다. 컴퓨터에서는 방향키 또는 WASD로 이동하고 마우스로 오른쪽 화면을 끌어 둘러봅니다.

관리동에 입수한 친구를 선택해 상태를 확인하고 먹이 반응을 보면 첫 돌봄이 완료됩니다. 수중에는 무료 Cute Fish Pack의 작은 물고기 무리, Nature Kit 바위와 직접 만든 해초·모래·수면이 보입니다.

해안 광장 왼쪽은 관리동, 오른쪽은 전시관입니다. Pirate Kit의 원본 건물과 문을 사용하며 문을 향해 약 1초 계속 걸으면 별도 실내로 들어갑니다. 가까이서 **문 열기**를 눌러도 됩니다. 뒤편의 오름형 구릉과 오솔길은 현재 배경입니다.

관리동에는 선장보다 높은 원형 사육 수조 3기와 공용 작업 데크·양끝 계단이 설치돼 있습니다. 계단으로 올라가 수조 앞에서 친구를 돌보고 반대편 계단으로 내려올 수 있습니다. 남쪽 출입문과 중앙 입수 지점은 유지합니다.

범돔·자리돔은 무료 Cute Fish Pack의 원본 형태와 수영 동작을 유지하고 색상·무늬를 바꾼 표현입니다. 보름달물해파리는 무료 원본을 변형해 봉긋한 반투명 우산, 중심 쪽으로 열린 말굽 모양 표시와 주름진 구완 네 개를 표현합니다. 우산이 빠르게 수축한 뒤 천천히 펴지고 잠시 떠가며 구완은 뒤늦게 따라 움직입니다. 가까이 보기에서 회전·확대·정지가 가능합니다. 생물의 모습과 동작은 게임용 근사 표현입니다.

수조 가까이에서 **전시 편집**을 열어 세 자리의 모듈과 생물을 고릅니다. 빈 수조를 선택하면 친구가 관리동으로 돌아오고 다른 자리로 옮길 수 있습니다. 관찰·꾸미기 달성은 유지하며 범돔 장식도 함께 옮겨집니다. 다른 수조에 전시 중인 친구는 먼저 관리동으로 돌려보내 주세요.

진행은 각 브라우저에 저장되며 기기 간 자동 동기화는 없습니다. 조작 안내의 **저장 기록 옮기기**에서 파일을 내보내거나 가져올 수 있습니다. 내용을 확인한 뒤 적용하며 교체 전 기록을 백업합니다. 파일이 없는 예전 진행은 완료 단계와 장식을 직접 고르는 복원을 제공합니다. 직접 고른 복원은 원본 기록의 정확한 이전과 구분됩니다.

검토 버전: `2026-10-16-jelly-stroke-2`. 같은 브라우저의 v1~v5 기록을 v6으로 이전하며 생물·관찰·꾸미기·장식·전시 배치를 유지합니다. 이미 입수한 생물은 첫 돌봄 안내 완료로 인정해 재수집을 요구하지 않습니다. 운반 중 생물도 유지합니다. 수중에서 재접속하면 안전한 진입 지점에서 이어집니다. 저장 안내에서 수중 탐사 도입 전 원본도 내려받을 수 있습니다.

PC Chrome에서 세 종의 잠수·수집·귀환·돌봄·중단·재접속, 해파리 형태 변화와 회전·확대·정지, 기존 진행 복원·전시·꾸미기·저장 내보내기와 작은 화면을 확인했습니다. 긴 이동 경로 자동검사는 시험 브라우저의 정지 위치 오차로 완주하지 못했습니다. 실제 안드로이드 성능·조작감과 기존 기기에서의 진행 유지는 사용자 검토를 기다립니다.

## 파일과 게시

`site/`에는 검토할 게임의 실행 파일과 자산·출처 안내만 있습니다. 제작 기록·시험 자료·개인 저장 파일은 포함하지 않습니다. 빌드나 외부 CDN 없이 정적 파일로 실행합니다.

GitHub Actions의 **Publish review build**를 `main`에서 수동 실행하면 `site/`만 GitHub Pages에 게시합니다. 파일을 올리는 것만으로 자동 재게시하지 않습니다. 검토 버전은 조작 안내와 `site/release.json`에서 확인할 수 있습니다.
