# 선장의 아쿠아리움

바다를 사랑하는 선장이 보물을 팔아 수족관을 짓고, 선원들과 바다의 소중함을 알리는 스마트폰 게임 시제품입니다. 제주는 첫 배경이며 다른 지역은 구현 전입니다.

[게임 열기](https://wishjosh.github.io/captains-aquarium/?v=2026-10-17-expedition-crew-1)

현재 검토 버전은 `2026-10-17-expedition-crew-1`입니다. 공식 Quaternius Cute Fish Pack의 흰동가리 한 종을 사용합니다. 원본 형상·몸의 색과 재질·뼈대·여섯 동작을 보존하고, 사용자가 선택한 흰자·큰 검은 눈동자·작은 광택은 표시용 눈 재질 복사본에 적용합니다. 이 눈 표현은 게임에 추가한 디자인입니다. B 조명과 원본 모델 파일은 유지합니다. 실제 세부 종과 서식 해역은 미정이며 제주 야생 생물이라고 단정하지 않습니다. 이전 범돔·자리돔·해파리와 배경 물고기 무리는 현재 실행에서 제외했습니다.

부두 사다리로 내려가기 → 수중 탐색·생물 직접 수집 → 사다리로 귀환 → 조수 운반 → 관리동 입수·상태 확인·먹이 돌봄으로 이어집니다. 전시관 배치·관찰·수조 장식은 별도 흐름입니다. 세 수조와 공용 작업 데크·양끝 계단을 유지하며 흰동가리 한 종을 관리합니다. 관리동 Anne·전시관 Mako에게 가까이 가서 누르면 기존 관리·입수·전시 편집을 엽니다. Henry 조수는 귀환 후 부두부터 관리동 입수까지 생물이 든 운반 수조를 들고, 선장이 지나간 계단·데크 경로를 따라옵니다. 수중에서는 조수를 표시하지 않습니다.

스마트폰은 가로로 사용합니다. 왼쪽을 누르고 끌면 수평 이동하며, 수중 오른쪽 세로 조작부로 상승·하강합니다. 손을 떼면 해당 방향의 이동을 멈추며 두 조작을 함께 사용할 수 있습니다. 생물 자체를 가까이에서 눌러 수집합니다. 먼 대상은 선택·접근 안내만 보여 줍니다. 부두 끝 사다리를 향해 계속 이동하면 내려가고, 수중에서 사다리에 접근해 상승하면 올라옵니다. 두 손가락 벌리기·모으기나 마우스 휠로 확대·축소하며, 시선은 제한된 범위에서 자동 보정합니다. 육지의 원본 건물 문을 향해 약 1초 계속 이동하면 출입합니다. 컴퓨터는 WASD·방향키, Q 상승·E 하강, +/- 확대·축소, 0 확대 초기화를 지원합니다.

진행은 같은 기기·브라우저에 저장되며 기기 간 자동 동기화는 없습니다. 조작 안내의 **저장 기록 옮기기**에서 파일을 내보내고 가져옵니다. 기존 저장 키와 v7 형식을 유지합니다. 이전 v1~v6 원본 기록은 `legacyProgress`에 보관하고 첫 저장 전에 별도 원본 백업도 남깁니다. 백업이 실패하면 이전 기록을 덮어쓰지 않습니다. 이전 생물을 흰동가리로 이름만 바꾸지 않으며 흰동가리는 새 수집으로 시작합니다. 이미 흰동가리 진행이 있는 경우 그대로 이어갑니다. 원본 기록은 이전 화면에서 별도 내보내기도 가능합니다. 사이트 데이터를 지우면 기록이 사라질 수 있습니다.

원본 보존·표시용 눈 분리·이전 19상태·현재 6단계 저장과 별도 시험 브라우저의 사다리 왕복·수평/수심 동시 터치·직접 수집·귀환·동료·돌봄·전시·관찰·꾸미기·재접속을 확인했습니다. 실제 안드로이드 성능과 사용자 기기에서의 외형·기존 기록은 검토 대기입니다.

## 게시 파일과 실행 방식

`site/`에는 실행에 필요한 명시적 허용 목록의 파일만 둡니다. 개발 비교 화면·시험 코드·개인 저장·원본 Blender 파일은 포함하지 않습니다. 파일 참조에 같은 검토 버전을 붙여 새 화면과 이전 스크립트가 섞이는 것을 줄입니다. GitHub Actions의 **Publish review build**를 `main`에서 수동 실행하면 `site/`를 GitHub Pages에 게시합니다. 검토 버전은 조작 안내와 `site/release.json`에서 확인합니다.
