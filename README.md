선장에게만 승인한 망원경과 걷기 파지를 적용했습니다. 작은 접안부는 배쪽·큰 렌즈는 등쪽을 향하며, 기존 원본 모델과 손가락·대기·걷기·인사 동작을 유지합니다. 사다리·잠수와 인사 중에는 망원경을 숨겼다가 돌아오면 다시 듭니다. 눈에 대고 보는 별도 행동은 아직 구현하지 않았습니다. Mako·Henry는 이전 공개본의 모습과 기능을 유지합니다.

Anne에게 승인한 스테인리스 먹이 양동이와 대기·걷기 파지를 적용했습니다. 손잡이는 손에 고정하고 금속 손잡이와 양동이 몸통은 작게 흔들린 뒤 안정됩니다. 원본 캐릭터·14개 동작과 손가락·몸통·다리·반대쪽 팔은 유지하며 왼쪽 위팔·아래팔만 보정합니다. 기존 사육 담당 위치와 입수·돌봄 기능은 유지하고 새 순찰 경로는 추가하지 않았습니다. 보류한 Mako·Henry 도구는 포함하지 않았습니다.

Quaternius 무료 원본을 바탕으로 흰동가리·가시복·깃대돔·뿔복 네 생물을 수집합니다. 원본 형태·뼈대·수영 동작을 보존하고 승인된 표시용 색·무늬·흰자 눈을 적용합니다. B 조명과 원본 GLB 파일을 유지합니다. 일반 장면의 크기 비율은 8:25:20:30이며 관찰 화면에서는 각 생물을 확대합니다. 이는 검토용 개체 크기이며 종별 평균·최대 크기나 모델의 정확한 종 판정이 아닙니다. 친근해서 먼저 사용한 흰동가리를 제주 야생 생물이라고 설명하지 않습니다. 이전 범돔·자리돔·해파리는 실행에서 제외하되 과거 진행은 보관합니다.

큰 배 탑승 → 제주 연안으로 출항 → 무인탐사정 진수 → 원격 관찰·이동 수조 유도 → 회수·귀항 → 조수 운반 → Anne 입수·상태 관찰·먹이 반응으로 이어집니다. 한 번에 한 생물을 운반하고 이미 입수한 생물은 다시 수집하지 않습니다. 관찰만으로 발견 기록을 남길 수도 있습니다. 유도 중에는 취소할 수 있고 문이 닫힌 뒤에만 수집을 저장합니다. 전시 없이 다음 탐사를 시작할 수 있습니다.

제주 연안에서 영감을 받은 가상 해역으로, 바위길·해조숲 가장자리·모래 물길을 둘러봅니다. 실제 장소·자생종·사육 수치의 재현은 아닙니다. 기존 큰 배와 네 생물·배경을 쓰고, 탐사정·인양 장치는 코드 도형으로 만들었습니다. 새로운 이미지나 외부 모델은 추가하지 않았습니다.

관리동의 높은 원형 수조 세 기·공용 데크·양끝 계단을 유지합니다. Anne의 첫 돌봄은 상태 관찰 2.7초와 먹이·반응 관찰 3.4초로 구성하며, 중단한 행동은 완료 처리하지 않습니다. 전시관 Mako의 편집·확대 관찰·흰동가리 장식은 별도 흐름입니다. 세 전시 자리에 네 생물을 교체해 놓을 수 있고 돌봄·관찰 기록은 유지합니다. Henry는 선장이 지나간 길·계단을 따라 이동 수조를 운반합니다.
