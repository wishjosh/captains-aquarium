# 선장의 아쿠아리움

바다를 사랑하는 선장이 보물을 팔아 수족관을 짓고, 선원들과 바다의 소중함을 알리는 스마트폰 게임 시제품입니다. 제주는 첫 탐험 지역이며 다른 지역은 구현 전입니다.

[게임 열기](https://wishjosh.github.io/captains-aquarium/)

현재 해안 수집 → 관리동 입수 → 전시관 배치·관찰의 흐름과 범돔 수조 꾸미기를 제공합니다. 관리동에서는 보관·전시 현황을 보고, 전시관에서는 관람길을 따라 사각 수조와 원통형 수조를 감상합니다. 화면 바닥을 누른 채 원하는 방향으로 끌면 걷고 손을 떼면 멈춥니다. 컴퓨터에서는 방향키 또는 WASD로 이동합니다.

진행은 각 브라우저에 저장되며 기기 간 자동 동기화는 없습니다. 조작 안내의 **저장 기록 옮기기**에서 파일을 내보내거나 가져오고, 내용을 확인한 뒤 적용할 수 있습니다. 파일을 꺼낼 수 없는 예전 진행은 완료 단계와 장식을 직접 고르는 복원을 제공합니다. 이는 원본 기록의 정확한 이전과 구분됩니다.

검토 버전: `2026-10-13-management-exhibition-1`. 기존 v1~v3의 수집·전시·관찰·꾸미기 기록을 보존하며 새 입구에서 시작합니다. 새 저장 형식은 v4이고 개편 전 원본 기록도 파일로 내보낼 수 있습니다. PC Chrome의 휴대폰 화면 모사에서 관리동·전시관 동선, 3종 임무·꾸미기·저장 이전과 320~1280px 화면을 확인했습니다. 실제 안드로이드 성능·조작감은 확인 전입니다.

## 파일과 게시

`site/`에는 검토할 게임의 실행 파일과 자산·출처 안내만 있습니다. 제작 기록·시험 자료·개인 저장 파일은 포함하지 않습니다. 빌드나 외부 CDN 없이 정적 파일로 실행합니다.

GitHub Actions의 **Publish review build**를 `main`에서 수동 실행하면 `site/`만 GitHub Pages에 게시합니다. 파일을 올리는 것만으로 자동 재게시하지 않습니다. 검토 버전은 조작 안내와 `site/release.json`에서 확인할 수 있습니다.
