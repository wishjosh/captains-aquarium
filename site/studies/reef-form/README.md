# 암반과 연산호의 무채색 비교 시안

2026-10-29 · 형태 검토용 · 사용자 미술 채택 전

사용자가 실제 문섬 사진을 기준으로 암반의 경사면·턱을 먼저 만들고, 연산호 한 종류와 군락을 무채색으로 비교하도록 요청했다. 별도 시안에서 이전 조형 / 암반만 / 한 군체 / 군락을 같은 시점으로 바꿀 수 있다. 기존 조향·터치 접근·관찰·확대·수집 흐름을 사용하며 비교판의 탐사 기록은 별도 저장한다.

참고는 해양시민과학센터 파란의 [2024년 4월 문섬 조사](https://greenparan.org/16/?bmode=view&idx=22777500)와 [6월 조사](https://greenparan.org/17/?bmode=view&idx=33837416)다. 4월 자료에서 자색수지맨드라미로 설명한 윤상훈 촬영 사진과 6월의 박승환 촬영 군락 사진을 형태 기준으로 삼았다. 원본 사진을 게임 자산에 넣지 않았다. 실제 종의 정밀 복원이나 실제 문섬 지형의 복제는 아니다.

암반은 독립 기둥 대신 바닥과 이어진 넓은 경사면, 폭과 위치가 다른 세 턱으로 구성했다. 연산호는 짧은 밑동, 굵기가 줄어드는 가지, 잔가지, 작은 입체 폴립으로 만들었다. 같은 종류의 가지 변형 세 개를 사용하고 크기·방향·간격이 다른 11군체를 배치했다. 생물 주변 말미잘은 기존 비교 기준으로 유지했다.

가림 검사를 위해 연결된 지형을 내부적으로 구역별 처리한다. 조형은 그대로 유지하면서 PC 1280×720의 10초 검사에서 초기 15.3fps에서 60fps로 개선됐다. 실제 휴대폰의 성능·발열은 별도 검토 대상이다. 정상 작동 검사와 자연스러움의 채택은 구분한다. 실행 검사 주소에 &check=1을 붙이면 기기 내에서 측정할 수 있고 결과는 전송하지 않는다.

왼쪽 조이스틱으로 움직이고 오른쪽 드래그로 둘러본다. 생물을 터치해 접근한 후 관찰을 누르고 확대해 비교한다. 두 손가락 확대 및 마우스 휠을 지원한다. 비교 버튼은 시점과 확대 목표를 초기화하지 않는다. 생물은 계속 움직이므로 연속 촬영 화면의 위치가 조금씩 다를 수 있다.
