# 연산호와 말미잘 · 한 개씩의 무채색 형태 시안

2026-10-30. 기존 작은 서식처에서 나뭇가지·막대 같은 인상이 남았다는 사용자 피드백에 따라 두 대상의 제작 방식을 나눈 별도 비교판이다. 기존 게임·공개 탐사판·저장 기록을 변경하지 않는다.

[스마트폰 실행](https://wishjosh.github.io/captains-aquarium/studies/soft-forms/?v=2026-10-30-soft-1)

## 형태의 차이

연산호는 타원형의 살집을 부드럽게 연결한 표면을 제작 단계에서 하나의 닫힌 메시로 구웠다. 큰 갈래·끝의 짧은 갈래·갈래 사이 틈이 이어지며 원통을 따로 붙이는 원본과 다르다. 말미잘은 중심의 낮은 입 주변 몸체와 세 층의 촉수 30개를 만들고, 중간부터 굽어 옆으로 퍼지는 곡선과 끝이 둥글게 닫히는 형상을 배치했다. 밑동을 암반에 묻었고 별도 화분·접지 원판은 없다. 조형·배치용 원본이며 특정 제주 종이나 실제 서식 분포를 복원한 것은 아니다.

원본 두 개는 이미지 없는 `assets/soft-forms.glb` 174,492바이트에 들어 있다. 연산호 2,388삼각형·말미잘 2,952삼각형이다. 무거운 표면 계산은 `tools/build-soft-forms.mjs`에서 미리 끝내며 휴대폰에서는 같은 원본과 재질을 공유해 쓴다. 암석은 앞서 준비한 Michael Hooper의 9부품 팩을 재사용한다.

## 정지 형태와 느린 움직임

기본은 무채색·정지 상태다. 선장·물고기와 함께 보거나 각 대상을 가까이 보고, 정면·옆면·뒷면·위에서 관찰할 수 있다. 끌어서 시점을 돌리고 휠이나 두 손가락으로 확대한다. 이전 형태 비교는 암반 위에서 드러나는 높이를 맞춰 형상을 비교한다.

‘느린 물살’을 켜면 밑동을 고정하고 연산호의 큰 갈래가 느리게 기울며 말미잘의 끝은 조금씩 늦게 따라온다. 끄면 원래 정지 형태로 부드럽게 돌아온다. 선장·물고기는 비교를 위해 고정돼 있다. 움직임과 그림자에 같은 변형을 적용한다. 두 형상과 고정점·위상 정보, 공용 재질·움직임 코드를 분리해 재사용한다.

정지본을 여러 방향·390px PC 세로 화면에서 확인한 뒤 움직임을 추가했다. 검사 5개는 형상 예산·다운로드 크기·닫힌 단일 연산호 표면·말미잘 몸체와 촉수의 연결 위치·고정점·원본 수치를 확인한다. 정지 확인과 에이전트의 조형 판단, 사용자의 최종 채택은 구분한다. 실제 갤럭시 노트20 울트라·아이폰16 프로의 동시 터치·발열·지속 성능은 검토 전이다. ‘10초 실행 검사’ 결과는 화면에만 표시하며 외부로 전송하지 않는다.

```sh
node tools/build-soft-forms.mjs
node --test references/soft-form-study/forms.test.mjs
node tools/prepare-soft-form-public.mjs
node --test previews/soft-form-public/site/studies/soft-forms/forms.test.mjs
```

출처·변경·라이선스는 [제작·자산 출처](ATTRIBUTION.md)를 따른다.

PC의 말미잘 근접·느린 물살 검사에서 1280×720 화면은 59.95fps·p95 16.8ms·33ms 초과 0/600회였고, 같은 PC의 390×844 화면도 59.95fps·p95 16.8ms·0/600회였다. 카메라를 고정한 두 시점의 실제 화면 픽셀 변화도 확인했다. 이는 실제 휴대폰의 측정값이 아니다.
