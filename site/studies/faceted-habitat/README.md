# 선장의 아쿠아리움 · 다각면체의 작은 서식처

2026-10-30. 기존 캐릭터·잠영·독립 카메라·터치 마법·수집·동행·귀환을 이어 쓰는 별도 실행 시안이다. 기존 공개 게임과 기록 키를 변경하지 않는다. 새로운 저장 키는 `captains-aquarium-faceted-habitat-v1`이다.

[실행](https://wishjosh.github.io/captains-aquarium/studies/faceted-habitat/?v=2026-10-30-habitat-2) · [휴대폰 실행 검사](https://wishjosh.github.io/captains-aquarium/studies/faceted-habitat/?v=2026-10-30-habitat-2&check=1)

## 형태와 제작 단위

- 암반은 단순 경사 지형과 낮고 넓은 암석 17개를 겹쳐 연결했다. 사이의 모래 물길·턱·틈으로 작은 관찰 장소를 만든다. 원본 암석 9부품을 분리한 50,040바이트 GLB를 공유하고 텍스처는 사용하지 않는다.
- 연산호는 짧고 통통한 가지가 이어지는 다각면체 3형태를 새로 만들고 11군락의 크기·회전·색·밀도를 달리했다. 원본의 단단한 산호 모음은 이번 장면에 넣지 않았다. 미세 폴립 대신 윤곽과 큰 갈래를 강조한다.
- 말미잘은 밑동을 각 지점의 바닥 아래에 묻고 바위틈에서 44개 촉수가 굽어 퍼지도록 만들었다. 둥근 화분·받침·접지 원판을 사용하지 않는다. 생물이 피하는 위치도 낮아진 촉수 높이에 맞췄다.
- `habitat-modules.mjs`가 공용 형상을, `habitat-layout.mjs`가 배치 자료를, `cove-scene.mjs`가 조립을 맡는다. 암석은 형상을 공유하고 연산호는 형태별 묶음으로 그린다. `?layout=ledge`는 같은 부품의 다른 배치 예시이며 양쪽 모두 군락의 실제 암석 접지와 충돌 범위를 검사한다. 다른 바다의 새로운 생태·생물까지 구현한 결과는 아니다.
- 이동과 지형의 높이는 같은 삼각면을 기준으로 한다. 멀리 있는 넓은 지형과 근접 부품의 역할을 나누며 촉수·가지에 작은 GPU 흔들림만 적용한다. 모바일 배율은 최대 1.25, 그림자는 1024 크기로 제한한다.

## 조작과 확인

왼쪽 조이스틱은 정지 후 바꾼 화면 기준으로 이동 방향을 고른다. 오른쪽 드래그는 카메라, 두 손가락 벌리기·모으기 또는 마우스 휠은 확대·축소다. 생물을 터치하면 마법으로 안심시키며 자동 접근한다. 조이스틱은 자동 접근을 취소한다. 도착 후 관찰 또는 수집을 선택하고, 마법 동행 뒤 배로 돌아가 결과와 도감을 확인한다.

게시용 검사 75개가 통과했다. 실제 입력으로 접근 취소·재접근·관찰·근접 확대·네 방향 회전·물방울 수집·동행 잠영·귀환 결과를 확인했다. 네 방향에서 선택 생물이 보였고 카메라 거리 6.8이 유지됐다. PC 1280×720·배율 1의 10초 검사에서는 평균 60fps, p95 16.8ms, 33ms 초과 0/600회였다. 측정 구간에 수집 효과를 포함했으며 최대 그리기 53회·40,498삼각형이었다. 서식처 자체는 17,786삼각형으로 캐릭터·수집 효과·그림자 중복을 제외한 값이다. 이 결과를 실제 스마트폰 성능이나 최종 미술 채택으로 보지 않는다.

실행 검사 주소에서는 탐사 시작 후 ‘실행 검사 시작’을 눌러 10초 동안 둘러보고 이동한다. 결과는 이 화면에만 표시하며 외부로 전송하지 않는다. 갤럭시 노트20 울트라와 아이폰16 프로에서 동시 터치·반복 잠영·발열·지속 성능은 실제 기기 검토가 필요하다. PC 검사는 이를 대신하지 않는다.

```sh
node --test references/faceted-habitat-study/*.test.mjs
node tools/prepare-faceted-habitat-public.mjs
node --test previews/faceted-habitat-public/site/studies/faceted-habitat/*.test.mjs
```

미술 형태와 자연스러움은 사용자 검토 전이다. 제주 남부 바다에서 영감을 받은 게임용 배치이며 특정 연산호 종, 실제 제주 서식 분포나 수중 지형의 복원이 아니다. 흰동가리는 기존 조작·서식처 비교용 생물이다.

원본·변경·사용 조건은 [제작·자산 출처](ATTRIBUTION.md)를 따른다. 선장·물고기·배와 라이브러리의 기존 출처도 유지한다.
