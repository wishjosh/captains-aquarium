`species-record.mjs`는 자리돔 기록을 별도 키 `captains-aquarium-faceted-habitat-v1:chromis-notata`의 종 식별자 포함 형식으로 저장한다. 이전 흰동가리 키·값은 변경하거나 자리돔으로 옮기지 않는다. 시작 화면에서 두 탐사를 오갈 수 있다. 관찰·수집 기록은 기존처럼 귀환 완료 때 반영한다.

자동 검사 128개가 통과했다. 실제 암반 위 생활 경로·세 선택 개체의 도착·일반 접근 회피·수동 취소·관찰 후 합류·남은 무리·세 마리 동행·종별 기록 보존을 포함한다. PC 직접 조작과 세로 화면 확인은 실제 휴대폰의 동시 터치·발열·지속 성능 검증을 대신하지 않는다. 기존 아이폰 이동+핀치와 이어 하기 팝업의 실기기 재확인은 남아 있다.

## 실제 휴대폰 확인을 위한 손가락 점검

[손가락 점검 모드](https://wishjosh.github.io/captains-aquarium/studies/faceted-habitat/?v=2026-10-31-touch-2&touchcheck=1)는 같은 탐사판의 선택형 표시다. 일반 링크에서는 점검 창·손가락 표시·기록을 실행하지 않는다. 탐사를 떠난 뒤 기기와 과제를 골라 ‘기록 시작’을 누르면 창이 접힌다. 손가락별로 조향·시점·확대가 표시된다. 과제를 마치고 ‘기록 끝내기’를 누른 뒤 체감·선호 확대를 선택하고 결과를 복사할 수 있다. 자동 전송·기기 자동 판별·영구 저장은 하지 않는다. 최대 한 번에 약 1분 기록하며 새로 시작하면 이전 결과를 대체한다.

점검은 두 손가락 인식, 확대 요청, 실제 배율 변화, 화면·암반·배율 한계를 구분한다. 원시 손가락 입력과 시작 영역도 기록하므로 인식되지 않은 시도가 있었다는 사용자 설명과 대조할 수 있다. 실제 시도 횟수를 자동으로 아는 것이 아니므로 성공률은 계산하지 않는다. PC 마우스 확인은 손가락 입력 없음으로 표시한다. 기기·체감·선호는 사용자 선택값이며 자동 측정과 구분한다. 창을 펼친 상태·표시 자체의 비용을 포함한 점검 중 프레임 수치는 일반 게임의 성능을 대신하지 않는다.

기록은 페이지 안에서만 유지된다. 결과 복사가 허용되지 않는 브라우저에서는 결과 글을 선택해 직접 복사한다. 화면을 벗어나거나 탐사를 멈추면 기록을 끝낸다. 터치 점검 구현은 `touch-session.mjs`의 집계와 `touch-audit.mjs`의 표시로 나눴고, 입력 처리기에는 선택형 관측 알림만 추가했다. 실제 휴대폰 검증을 마쳤거나 조작·확대 방식을 최종 채택했다는 뜻은 아니다.

## 조향과 핀치, 두 확대 방식의 비교

2026-10-31. 화면 왼쪽 전체를 조향 시작 영역으로 쓰던 방식을 왼쪽 아래 조작부로 좁혔다. 장면의 나머지 영역은 한 손가락 둘러보기, 두 자유 손가락 핀치다. 조이스틱을 이미 잡은 손과 오른손은 기존처럼 잠영과 둘러보기를 유지한다. 두 자유 손가락이 핀치를 시작하면 둘러보기·생물 터치만 정리하고 왼손 조향·깊이 조작·키보드 이동은 유지한다. 핀치는 자신이 맡은 손가락의 이벤트만 처리하며 조이스틱은 확대 중에도 새로 잡거나 움직이거나 뗄 수 있다. 남은 확대 손가락은 모두 떼기 전까지 둘러보기로 바뀌지 않는다. 이동하면서 확대하려면 왼손 조이스틱과 오른손 두 손가락(총 세 손가락)을 쓰거나, 왼손 조이스틱과 오른손 ＋·− 버튼(총 두 손가락)을 쓴다. 수동 이동이 없을 때 자동 접근·귀환은 핀치 동안 쉬었다가 이어 간다. 수동 조향이 들어오면 기존대로 자동 이동을 취소한다. 정지·재개는 실제 화면 이탈·일시정지 버튼으로 처리하며 보이는 화면의 포커스 변화만으로 멈추지 않는다. 빠른 재시도·취소·세 번째 손가락·포인터 잡기 권한 변경·핀치 직후 새 버튼 터치를 검사한다.

기본 확대는 시야각 49도를 유지하며 카메라가 다가가거나 물러나는 방식이다. 초기 거리 범위는 기본의 65~130%다. 선장과 가까운 선택 생물이 함께 보이는 범위와 확대 방향의 실제 암반 여유가 부족하면 더 다가가는 요청을 제한한다. 거리 여유 검사는 확대 요청 때만 하며, 시점 회전 때문에 카메라를 갑자기 밀어 넣거나 밖으로 튕기지 않는다. 회전 중의 근접 암반은 기존 부분 가림 보정을 이어 쓴다. 따라서 모든 시점의 완전한 카메라 충돌 회피를 뜻하지 않는다.

오른쪽 위 −·기본·＋로도 조절할 수 있다. 그 아래 ‘확대: 다가가서 보기 / 화면 확대’를 눌러 같은 중심·범위에서 확대 원리를 비교한다. 전환은 부드럽게 하며 확대 기준점의 대상 크기를 대체로 유지한다. 화면 확대는 이전 시야각 방식과 비교하지만 이전의 최대 3.2배와 먼 배경을 자동 확대 중심으로 삼던 규칙은 복구하지 않는다. 빈 배경에서 핀치해도 멀리 있는 바위로 중심이 옮겨가지 않는다. 관찰 선택만으로 자동 확대하지 않는다.

해초는 이동 충돌이 없는 식생이다. 기존 군락이 바위의 넓은 충돌 여유와 겹쳐 있던 배치를 통과 가능한 물길로 옮기고, 가까운 몸에 잎이 살짝 눕다가 돌아오도록 했다. 새 모델·이미지·그리기 묶음은 추가하지 않았다. 자세한 상하·좌우 위치와 반응은 `seaweed.mjs`, 확대 범위·화면 유지 계산은 `zoom-camera.mjs`로 분리했다.

핀치 입력 검사는 실제 처리기를 함께 호출하는 재현 검사이며 물리 스마트폰의 터치 성공률 측정과 다르다. PC 직접 조작·390px 화면 확인과 별개로 노트20 울트라·아이폰16 프로에서 가운데를 가로지르는 핀치, 조향 후 핀치, 빠른 반복, 실제 발열·지속 성능을 확인해야 한다.

## 첫 말미잘 서식처의 생활과 관찰

`cove-scene.mjs`가 실제 말미잘의 밑동·촉수 높이와 암반 표면을 읽어 생활 지점을 만든다. `habitat.mjs`의 머무는 자리·피신처·출입점·가장자리와 경로는 이 배치에 묶인다. 암반 표면 조회는 장면 준비 때 하고 매 프레임 다시 하지 않는다. 새 이미지·모델·그리기 묶음은 추가하지 않았다.

흰동가리는 촉수 가까이에서 짧게 이동하고 머문다. 일반 접근에는 말미잘 쪽으로 피하고, 움직임을 멈추고 기다리면 잠시 모습을 보인다. 계속 들이대면 피신을 유지한다. 터치하는 마법은 놀람을 가라앉히며, 실제 출입점을 거쳐 보이는 가장자리로 나오게 한다. 선택은 생물의 이동과 선장의 정지가 모두 안정된 뒤 열린다. 조이스틱을 움직이면 접근을 취소하고 자연 반응으로 돌아간다.

관찰에서는 말미잘 가까이로 돌아가기·자리 바꾸기·살짝 나오기·가장자리에서 쉬기를 약 12초 흐름으로 연결했다. 수집은 관찰을 끝낼 필요 없이 선택할 수 있다. `habitat-observation.mjs`는 실제로 보이는 상태에서 머무는 장면과 이후 나오는 장면을 본 경우만 이번 탐사 결과에 짧은 문장을 더한다. 이 상세 문장은 현재 탐사 결과용이며 영구 도감 항목을 새로 만들지는 않는다. 기존 발견·관찰·수집 기록과 저장 형식은 유지한다.

`fish-motion.mjs`는 실제 이동 속도에 따라 몸의 상하 기울기와 회전 기울기를 작게 보탠다. 지느러미 속도는 기존 이동 속도 연결을 이어 쓴다. 발견 명칭은 첫 서식처에 가까워져 잠깐 이상 생물이 보일 때 드러나며, 멀리서 보이는 주황빛 움직임은 접근의 단서로 남긴다.

이번 행동은 흰동가리를 이용한 게임용 시안이다. 제주 대표종·실제 생태 행동의 정확한 재현으로 채택한 것이 아니며, 다른 두 생물의 생활 영역과 제주 본편의 생물 구성은 다음 검토 대상이다.

## 형태와 군락

단일 형태 비교판의 같은 GLB를 그대로 공유한다. 연산호는 살집이 이어지는 원본 2,388삼각형, 말미잘은 낮은 중심 몸체와 촉수 30개를 가진 원본 2,952삼각형이다. 원본 파일은 이미지 없이 174,492바이트다. 표면 생성은 제작 단계에서 끝내므로 실행 중에는 다시 계산하지 않는다.

연산호 13군체는 뒤쪽 밀집부 5개·중간 암반 4개·성긴 가장자리 4개다. 크기 범위는 0.15~0.84이며 회전·폭·깊이를 조금씩 달리한다. 밀집부의 큰 개체 사이에는 작은 개체가 끼고, 가장자리는 작은 군체와 드러난 암반으로 이어진다. 관찰 장소 앞에는 틈을 남겼다. 한 원본을 한 묶음으로 그리며 군체별 물살 시점을 조금씩 달리하되 원본을 회전해도 같은 흐름 방향으로 움직인다. 물살로 움직이는 범위까지 포함한 경계를 계산해 화면 밖의 군락 묶음은 그리지 않는다. 말미잘은 실제 암석 접지점을 찾아 밑동을 묻고 기존 생물의 숨는 높이와 맞췄다.

이동·충돌용 암석은 그대로 유지하고 연산호·말미잘도 기존의 국소 가림 보정에 포함했다. 선택 생물과 선장을 막는 부분만 부드럽게 걷어 내며 카메라를 가까이 밀거나 자동 확대하지 않는다. 원래 자연스러운 숨기와 마법으로 안심시키는 규칙을 이어 쓴다. 움직이는 몸체와 그림자는 같은 변형을 사용한다.
