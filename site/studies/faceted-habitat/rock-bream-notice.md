# 돌돔 한 종 비교 시안 · 2026-11-10

돌돔은 Quaternius의 Red Snapper(CC0) 원본을 바탕으로 만든 양식화된 표현입니다.
https://poly.pizza/m/BRKfDKwPTv

원본 GLB는 변경하지 않았습니다. 표시 복사본의 몸 높이·폭·입 윤곽·꼬리를 조정하고, 몸 표면과 원본 뼈대의 가중치에 연결한 등·뒷·배지느러미를 만들었습니다. 기존 자리돔의 눈 표현을 재사용하고 몸의 띠·밝은 배·지느러미 결을 추가했습니다. 원본 유영을 유지하면서 기존 가슴지느러미에 작은 보조 움직임을 더했습니다.

형태 근거: 부산광역시 수산자원연구소 돌돔 설명·사진의 높은 체고, 납작한 몸, 부리 모양 입과 7개 세로 띠를 참고했습니다. 사진을 게임 파일이나 텍스처로 사용하지 않았습니다.
https://www.busan.go.kr/fisheries/frfishpoint01

비교 대상 자리돔은 기존 RedSnapper 기반 수정안, 가시복은 기존 Quaternius Puffer.glb와 기존 게임 재질을 사용합니다. 기존 돌돔은 제주 생물 다양화판의 직접 제작 형상입니다. 세 물고기는 비교를 위해 같은 길이로 표시하며 실제 생물의 상대 크기가 아닙니다. 정확한 종 동정용 모형이나 최종 외형 채택을 뜻하지 않습니다.

본게임·공개 탐사·기존 자산 파일은 수정하지 않은 별도 비교판입니다. 원본과 라이선스는 기존 자산 출처 안내를 따릅니다.
