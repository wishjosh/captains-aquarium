# 선장의 아쿠아리움 · 한 번의 탐사

수집 게임의 준비 → 탐사 → 관찰·마법 수집 → 동행 → 귀환 → 결과·도감 → 다음 탐사를 잇는 별도 시안입니다.

[시안 실행](https://wishjosh.github.io/captains-aquarium/studies/one-expedition/?v=2026-10-29-view-2)

모래 여울에서 바위턱과 해초가로 이어지는 작은 물길을 둘러봅니다. 같은 흰동가리 세 마리가 모래길 왕복, 바위 가장자리 순환, 해초 옆 높이 변화로 움직입니다. 가까운 시야 안의 생물을 발견하면 기록하고, 이름표는 더 가까이에서 표시합니다. 이는 탐사 경험을 검토하는 행동 시안이며 실제 생태 설명은 아닙니다.

멈춰서 오른쪽을 드래그해 시점을 바꾸면 왼쪽 조이스틱의 상하좌우도 새 화면을 기준으로 이동 방향을 고릅니다. 생물을 터치하면 자동 접근하며 도착한 뒤 관찰 또는 수집을 선택합니다. 접근 중에는 대상이 작은 범위에 머무르고, 관찰 중에는 가까운 곳에서 움직입니다. 카메라가 자동으로 확대되거나 돌아가지는 않습니다. 오른쪽 화면의 두 손가락 벌리기·모으기로 확대·축소합니다. 마우스 휠도 지원하며 기본 거리 버튼으로 돌아옵니다. 관찰 중 확대는 선택한 생물을 중심으로 하고, 선장과의 물리적 카메라 간격을 줄이지 않는 시야각 확대를 사용합니다. 왼쪽 조이스틱과 오른손 시점 조작은 핀치와 구분합니다.

그냥 다가가면 야생 생물이 선장을 피하고 몸과 간격을 유지합니다. 생물을 터치하는 행위도 안심시키는 마법으로 해석하며, 선택한 대상은 도망가지 않고 가까운 곳에 머뭅니다. 이동 입력은 자동 접근과 귀환을 취소합니다. 키보드는 W/S 화면 안쪽·앞쪽, A/D 화면 좌·우, E/Q 높이 조절을 지원합니다.

수동 잠영 속도는 앞선 시안보다 약 35% 높였습니다. 멈출 때 밀리는 거리는 이전 수준으로 맞췄고, 자동 접근과 귀환은 기존 속도로 유지합니다.

물방울이 풀려도 마법의 효력과 느린 윤곽빛은 남고 생물이 선장을 따라옵니다. 배로 돌아가면 탐사 결과와 도감을 확인하고 다시 출항할 수 있습니다. 관찰만 하거나 빈손으로 돌아와도 탐사를 마칠 수 있습니다. 관리·돌봄·전시는 포함하지 않습니다.

흰동가리 한 종의 세 마리로 전체 흐름을 검토하는 시안입니다. 실제 스마트폰의 동시 터치·성능·소리와 반복할 때의 재미는 사용자 검토가 필요합니다. 기존 게임과 분리된 저장 키를 사용하며 귀환 완료 때만 누적 기록을 남깁니다. 진행 중 탐사는 새로고침 이후 복원하지 않습니다.
