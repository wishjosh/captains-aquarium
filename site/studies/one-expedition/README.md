# 선장의 아쿠아리움 · 한 번의 탐사

## 화면 안정과 선장·바위 가림 보정 — 2026-10-29

터치 접근은 선택 당시 시점을 기준으로 생물 옆의 빈자리에서 멈추도록 바꿨다. 도착 쪽은 접근 중 고정하며 조이스틱 입력은 즉시 취소한다. 화면 중심에는 선택한 생물만 반영하고 지나가는 다른 생물은 반영하지 않는다. 자동 확대와 시점 회전은 없다.

바위 때문에 카메라를 선장 쪽으로 밀지 않고 편안한 거리를 유지한다. 카메라와 선장·선택 생물을 가로막는 바위의 일부만 부드럽게 걷어 내고, 선택한 생물이 몸에 가리면 겹친 몸 부분만 옅게 한다. 잠깐 스치는 가림에는 반응하지 않고 해제도 늦춰 깜빡임을 줄인다. 원래 충돌과 그림자는 유지한다. 표면 표현은 기기의 부드러운 가장자리 처리를 우선 사용하고, 미지원 기기에는 고정된 점무늬 처리를 사용한다.

브라우저 직접 조작으로 몸 뒤 정렬·바위 앞 관찰과 짧은 방향 입력을 확인했다. 바위 보정 중 7회 표본에서 거리 6.8·시야각 49°·시점 방향이 유지됐다. 수동 확대 뒤 시점 회전에서도 사용자가 정한 확대 목표가 유지됐다. 실제 스마트폰의 성능·동시 터치·반복 체감과 가림 표현의 미술 완성도는 사용자 검토 전이다.

## 대표 서식처와 생물 행동 — 2026-10-29

첫 생물의 생활권을 말미잘 바위틈으로 만들었다. 곡선 촉수와 끝의 색 변화·느린 흔들림, 낮은 바위턱과 높은 암반, 바닥 접지 그림자를 추가했다. 첫 생물은 가장자리에서 짧게 헤엄치고 쉬며, 일반 접근에는 말미잘 안쪽으로 물러난다. 선장이 서식처에서 충분히 멀어진 뒤 다시 나온다. 터치하면 안심하며 보이는 가장자리로 천천히 나오고, 너무 가까운 선장은 작은 후진으로 거리를 확보한다. 움직임과 거리가 안정된 뒤 관찰/수집을 선택한다. 관찰 강제 대기는 없으며 수집·동행·귀환·도감은 기존 흐름이다. 나머지 두 생물은 이전 비교용 행동을 유지한다.

세로 화면에서는 선장과 선택한 생물을 함께 담도록 화면 중심의 비중을 조정했다. 자동 확대·카메라 회전은 추가하지 않았다. 앵무새는 원본을 64% 크기로 모자 가운데 정수리 표면에 앉혔다. 의족 끝에는 같은 나무 재질의 비틀린 세 날개와 둥근 날끝을 결합하고 금속과 테두리를 없앴다. C의 휘어짐·비틀림과 B의 둥근 끝을 결합한 작은 3엽 나무 스크류다. 강한 추진 장치보다 선장의 수영에 개성을 더하는 포인트로, 가장 빠를 때도 약 2.6초에 한 바퀴 돈다. 정지·후진에는 회전하지 않으며 전진 잠영 속도에 따라 회전한다. 의족은 잠영 중 더 곧게 유지하고 원래 다리와 팔의 수영 동작을 이어 쓴다. 앞선 네 방향 점검과 이번 함께 보기에서 장식의 직접 가림은 없었지만 당시 남았던 몸 뒤 정렬의 생물 가림과 바위 옆 카메라 밀림은 위 후속 보정에서 다뤘다. 게임용 행동·조형 시안이며 실제 종·제주 생태의 재현이나 최종 그래픽 채택으로 보지 않는다.

왼쪽 조이스틱은 정지 후 바꾼 화면을 기준으로 이동 방향을 고릅니다. 오른쪽 드래그는 카메라, 두 손가락 벌리기·모으기는 확대·축소입니다. 마우스 휠과 기본 거리 버튼도 지원합니다. 이동 입력은 자동 접근과 귀환을 취소합니다. 키보드는 W/S/A/D, 높이 조절은 E/Q입니다.
