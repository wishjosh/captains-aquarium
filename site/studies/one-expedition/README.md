# 한 번의 탐사 시안

> 2026-10-28 · 독립 수집 게임의 반복 흐름 · 로컬 구현·직접 조작 확인 · 사용자 체감 채택·실제 기기·본게임 적용 전

준비 → 잠영·발견 → 터치 접근 → 관찰 또는 마법 수집 → 동행 → 귀환 → 탐사 결과·도감 → 다음 탐사를 이어 보는 실행본이다. 관리·돌봄·전시는 포함하지 않는다. 기존 공개 게임과 각 조작 시안은 수정하지 않았다.

## 실행과 조작

저장소 루트를 제공하는 로컬 서버에서 `/references/one-expedition-study/`를 연다. 현재 검토 주소는 `http://127.0.0.1:54990/references/one-expedition-study/`다. 별도 설치·외부 서비스 없이 기존 자산과 모듈을 읽으며 별도 공개 페이지로 게시한 실행본이다.

- 왼쪽 드래그: 위·아래 전진/감속/후진, 좌우 선장 회전. 오른쪽 드래그: 독립 시점. 위·아래 높이 버튼도 제공한다.
- 키보드: W/S 전진·후진, A/D 회전, E/Q 상승·하강. 방향키도 지원한다.
- 보이는 생물을 터치하면 자동 접근한다. 조이스틱이나 이동 키 입력은 접근을 즉시 취소한다.
- 도착하면 관찰/수집을 선택한다. 관찰 중에는 ‘다른 행동 선택’으로 돌아갈 수 있다.
- 수집하면 물방울의 마법 부여 → 물막 해제 → 합류 → 동행으로 이어진다. 물막이 사라져도 마법의 효력과 느린 윤곽빛은 남는다.
- ‘배로 돌아가기’는 입수 지점으로 자동 귀환한다. 조이스틱으로 취소할 수 있고 동행 생물이 합류하기 전에는 결과를 확정하지 않는다.
- 귀환 결과에는 발견·관찰·동행 수와 탐사 시간이 남는다. 관찰만 하거나 빈손으로 돌아와도 다음 탐사를 시작할 수 있다.
- ‘잠시 쉬기’와 창 비활성화 시 탐사를 멈추고 같은 상태로 이어 간다. 진행 중 탐사는 새로고침 이후 복원하지 않는다.

흰동가리 한 종의 독립 인스턴스 세 마리를 사용한다. 종·지역의 다양성, 목표·제한·보상 전체를 완성한 상품 버전은 아니다. 이번 검토 대상은 발견·선택·동행이 귀환의 성취와 다음 출항으로 자연스럽게 이어지는지다.

## 저장과 원본의 분리

시안 전용 `captains-aquarium-one-expedition-preview` 키만 사용한다. 귀환이 끝나면 탐사 횟수·누적 수집·발견/관찰 여부를 저장하며 결과 화면을 반복해서 그려도 중복 집계하지 않는다. 도감은 이 기록을 표시한다. 기존 공개 게임의 저장을 읽거나 덮어쓰지 않는다. 시안 기록이 손상됐거나 저장이 막혔다면 기존 값을 덮어쓰지 않고 화면을 닫기 전까지 메모리로 진행한다. 직접 검토 중 생성한 탐사 기록이 같은 브라우저에 남아 있다.

## 확인한 범위와 남은 판단

`node --test references/one-expedition-study/expedition.test.mjs`의 8개 검사에서 완료 시 한 번만 집계, 귀환 취소, 마법 중·뒤처진 동행 대기, 세 마리 집계, 관찰 전용·빈 탐사, 다음 탐사 초기화와 누적 유지, 저장 검증을 확인했다.

실제 화면에서 세 마리를 차례로 수집해 귀환·결과·도감을 열었다. 관찰만 한 두 번째 탐사와 빈 세 번째 탐사도 종료했다. 접근 취소는 키보드와 세로 화면의 조이스틱 드래그로, 귀환 취소는 이동 키로 확인했다. 정지 상태에서 카메라를 돌려도 선장 방향이 유지됐고, 잠시 쉬기·복귀와 새로고침 후 누적 기록도 확인했다. 844×390 및 390×844 브라우저 화면을 확인하고, 세로 화면에서 첫 생물이 밖으로 밀리던 카메라 거리를 보정했다. 초기 도감 조명 준비 오류를 수정한 뒤 추가 화면 오류는 발생하지 않았다.

검토 근거는 `_workbench_/_temp_/captains_aquarium_one_expedition/`에 있다. 실제 Android/iPhone에서 두 손가락 동시 입력·성능·소리와 반복 탐사의 재미는 확인 전이다. 사용자 채택, 스마트폰 공개 게시와 본게임 적용도 전이다.

## 재사용한 구성

기본 잠영의 core/input/actor, 터치 접근의 Approach, A안의 School·윤곽빛과 기존 효과음·선장·흰동가리·큰 배·수중 자산을 재사용한다. 새 파일은 expedition.mjs(한 판과 기록), expedition.test.mjs, game.js, index.html, game.css, 이 안내다. 잠영·접근·동행의 핵심 모듈은 담당 시안에서 불러온다.
